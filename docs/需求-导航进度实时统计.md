## 1. App“开启 Rviz”使用的路线 Topic

`debug start_app.sh` 启动 App 后，“开启Rviz”按钮进入 2D 定位或导航模式时，加载：

```text
localization/rviz_cfg/localization_2d.rviz
```

该 RViz 中三条路线均为 `nav_msgs/msg/Path`：

| 颜色 | RViz 名称 | Topic | 含义 |
|---|---|---|---|
| 绿色 | Global Plan | `/global_path` | Nav2 计算并由多航点路径节点拼接发布的全局规划路线；重规划时会变化 |
| 红色 | Path (2D) | `/global_localization/path` | 基于平滑定位 `/localization` 累积得到的机器人实际行走轨迹 |
| 蓝色 | Local Plan | `/local_path` | RL/PRIEST 局部规划器生成的短距离局部执行路线，后续交给 Nav2 DWB `FollowPath` 执行 |

简要调用路径：

```text
App“开启Rviz”
  -> robot_console/main_window.py: toggle_rviz()
  -> rviz2 -d localization/rviz_cfg/localization_2d.rviz
  -> 显示 /global_path（绿）、/global_localization/path（红）、/local_path（蓝）

RViz /clicked_point
  -> global_path_sequence_publisher
  -> Nav2 /compute_path_to_pose
  -> /global_path（绿色全局规划）

/aft_mapped_to_init + /map_to_odom
  -> transform_fusion
  -> /localization
  -> global_localization 累积
  -> /global_localization/path（红色实际轨迹）

/global_path + /subgoal + /scan + /odom
  -> RL/PRIEST 局部规划器
  -> /local_path（蓝色局部执行路线）
  -> Adapter / FollowPath / DWB
  -> /cmd_vel -> /NAV_CMD
```

## 2. 导航进度统计口径

独立脚本订阅：

- `/global_path`：当前全局规划路线，用于计算当前位置投影点到终点的剩余路程；路线变化后立即按新路线重算。
- `/global_localization/ui_horizontal_pose`：机器人实时水平位姿，用于累计本次统计启动后的实际已走路程。
- `/global_localization/path`：用于绘制红色实际轨迹。
- `/local_path`：用于绘制蓝色局部执行路线；若其坐标系不是 `map`，通过 TF 转换后绘制。

进度公式：

```text
进度(%) = 已走实际路程 / (已走实际路程 + 当前全局路线剩余路程) * 100
```

说明：收到第一条有效 `/global_path` 后开始累计已走路程；更新全局路线不清零已走路程，只更新剩余路程。未收到有效全局路线时进度为 0。发布值限制在 0～100。

输出：

- 10 Hz 发布 `/navigation/progress_percent`，类型 `std_msgs/msg/Float32`。
- 5 Hz 持续覆盖 `${WORKSPACE}/tmp/navigation_progress.jpg`。
- JPG 中绿色为全局规划路线，红色为实际行走轨迹，蓝色为局部执行路线，并标注进度、已走距离和剩余距离。
